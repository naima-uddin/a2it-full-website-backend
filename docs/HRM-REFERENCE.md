## PAYROLL BUSINESS LOGIC

```
Daily Rate   = Monthly Salary ÷ 23
Basic Pay    = Daily Rate × Present Days

Late Deduction    = floor(lateDays ÷ 3) × Daily Rate
Absent Deduction  = absentDays × Daily Rate
Leave Deduction   = unpaidLeaveDays × Daily Rate
Half Day          = halfDays × (Daily Rate ÷ 2)

Onsite Benefits (workLocationType === 'onsite'):
  Allowance = presentDays × 10 BDT
  Deduction = 500 BDT fixed
  Net       = Allowance - Deduction

Meal Deduction (if active subscriber):
  = Total Monthly Food Cost ÷ Active Subscribers

Net Payable = BasicPay + Overtime + Bonus + Allowances
            - LateDeduction - AbsentDeduction - LeaveDeduction - HalfDayDeduction
            ± OnsiteNet - MealDeduction
```

## AUTH FLOW

```
POST /api/v1/unified-login { email, password }
  → find user by email
  → bcrypt.compare password
  → generateToken(user) [JWT, 7d]
  → return { success, token, role, _id, firstName, ... }

Frontend:
  role=employee   → store employeeToken + employeeData → /profile
  role=admin      → store adminToken + adminData → /dashboard
  role=moderator  → store moderatorToken + moderatorData → /moderatorDashboard
  cacheExpiry     = now + 1 hour
```

## KEY BUSINESS RULES

1. **Working days basis:** 23 days fixed per month (not calendar days)
2. **Late rule:** 3 late days = 1 day salary deduction
3. **Absent:** 1 absent day = 1 day salary deduction
4. **Half day:** 0.5 day deduction
5. **Leave:** Unpaid/HalfPaid leave deducted, Paid leave not deducted
6. **Onsite benefits:** 500 BDT/month deduction + 10 BDT/present day allowance (net effect applied to payroll)
7. **Meal deduction:** total monthly food cost ÷ active subscribers
8. **Holidays:** Auto-synced from Bangladesh public holiday API every Jan 1 + daily holiday attendance auto-mark
9. **Session cache:** 1-hour expiry in localStorage, auto-logout on expiry
10. **Role hierarchy:** superAdmin > admin > moderator > employee
11. **Employee ID:** EMP-XXXXXXX (auto-generated)
12. **Moderator ID:** MOD-XXXXXXX (auto-generated)
13. **Night shift:** Supported — cross-midnight clockIn/Out handled, autoClockOutIsNextDay flag
14. **Welcome email:** Sent on user creation with credentials, role, salary info (HTML template)
15. **Soft delete:** Users, Attendance, Payroll use isDeleted flag (not hard delete)
